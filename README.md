# homebrew-tap

Homebrew tap for [Song Notifier](https://github.com/minhquandev91/song-notifier).

```sh
brew tap ungive/media-control && brew tap minhquandev91/tap
brew trust ungive/media-control minhquandev91/tap   # recent Homebrew only loads trusted taps
brew install --cask song-notifier
```
